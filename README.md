# Sales Mini Project

## Overview
This project analyzes an online retail transactions dataset (2010 to 2011) to understand customer behavior, product performance, and revenue distribution across countries and time.

## Data
Dataset source: https://www.kaggle.com/datasets/vijayuv/onlineretail

The notebook expects an OnlineRetail CSV file. Update the file path in the notebook to match your local location before running.

## Workflow
- Load the dataset and preview records.
- Clean data by removing missing customers and invalid quantities or prices.
- Create a total price feature.
- Explore top countries, products, and customers by revenue.
- Analyze monthly revenue trends and product performance.
- Visualize results with bar charts and heatmaps.

## Requirements
- Python 3
- pandas
- numpy
- matplotlib
- seaborn

## How To Run
1. Open the notebook in VS Code or Jupyter.
2. Update the CSV path to your local file.
3. Run all cells in order.

## Outputs
The notebook generates summary tables and charts for revenue by country, top customers, monthly trends, top products, and feature correlations.
